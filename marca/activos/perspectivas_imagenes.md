# 1) Perspectivas base 

1. **Tres cuartos delantero**
   La más útil como imagen principal muchas veces. Enseña a la vez puntera, pala, abertura/escote, volumen y parte del lateral.

2. **Perfil exterior**
   La mejor para leer silueta general, tacón/cuña/plataforma y curva lateral.

3. **Frontal**
   La mejor para simetría, forma de puntera y lectura de la abertura delantera.

4. **Cenital / superior**
   La mejor para interior visible, plantilla, forma de la boca del zapato y relación puntera–garganta–empeine.

5. **Tres cuartos trasero**
   Muy útil para talón, cierre trasero, collarín/talonera y continuidad del tacón.

6. **Inferior / planta / suela**
   La mejor para silueta de la suela, enfranque y base del tacón.

7. **Detalle libre**
   Para textura, costuras, hebillas, trenzados, apliques, etc.
