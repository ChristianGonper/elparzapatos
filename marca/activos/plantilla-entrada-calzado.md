## Fase 1: Chequeo Anatómico Rápido (A - J)

*Anotaciones breves de trabajo. No publicar todo; solo comprobar lo que las fotos muestran.*

- **A. Identidad:** Familia (salón / sandalia / slingback / cuña / bailarina) | Proporción | Exposición del pie.
- **B. Delantera:** 
  - *Puntera:* Redonda / almendrada / puntiaguda / cuadrada / toe spring.
  - *Pala:* Lisa / delantal / capuchón / cobertura sobre empeine.
  - *Garganta:* En U / en V / recta / asimétrica / profundidad de escote.
- **C. Línea de calce:** Continua / interrumpida / baja en laterales / envolvente.
- **D. Trasera:** Talón cerrado / destalonado / talonera / altura de collarín.
- **E. Tiras y cierres:** Ancla (tobillera) / empeine / T-strap / cruzadas / hebilla / elástico.
- **F. Elevación:** Familia de tacón (aguja / kitten / bloque / bobina / cubano / cuña / plataforma) | Pecho | Tapa.
- **G. Base y suelo:** Suela | Enfranque visible | Puntos de contacto.
- **H. Interior visible:** Plantilla | Forro | Grabado de marca.
- **I. Material aparente:** Acabado liso / granulado / textil / charol / brillo / mate *(solo afirmar lo observable)*.
- **J. Ornamentos:** Lazos / hebillas / costuras vistas / remates singulares.
